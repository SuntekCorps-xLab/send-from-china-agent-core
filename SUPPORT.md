# Support

Use the repository's **Setup help** issue form for sanitized local setup
questions and **Bug report** for reproducible defects. Use **Feature request**
for roadmap proposals.

Before opening an issue:

1. Run `npm run verify` from the repository root.
2. Check `docs/TROUBLESHOOTING.md` and the relevant quickstart.
3. Reduce the report to synthetic data and remove tokens, account identifiers,
   private URLs, customer data, and production responses.

This community channel covers the public reference implementation. It does not
provide an SLA, provision hosted tenant credentials, investigate a private
deployment, quote shipping, or operate a purchasing workflow.

Report suspected vulnerabilities through the private process in `SECURITY.md`,
not through a public issue.
